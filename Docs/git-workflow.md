# Git Workflow

This project uses a simple Agile/Scrum Git workflow.

## Branches

### main

The `main` branch contains the final stable version of the project.

Code is merged into `main` only after it has been completed, reviewed, tested, and accepted.

### develop

The `develop` branch is the main working branch.

All completed feature branches are merged into `develop` through pull requests.

### feature branches

Each feature is developed in its own branch.

Branch naming format:

```text
feature/feature-name
